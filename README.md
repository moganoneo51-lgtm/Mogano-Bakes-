# Mogano-Bakes-
Mogano Bakes website project for WEDE2020 Web Development. 

## Part 2 – CSS and Responsive DesignThe website was updated with an external CSS stylesheet and responsive design features. Typography, layout, visual styling, navigation states, breakpoints, relative units, and responsive images were implemented.

### Testing

The website was tested on desktop and mobile screen sizes. Navigation links, the enquiry form, and responsive images were checked. The mobile layout changes the navigation to a vertical layout and ensures content and images fit within the screen.
